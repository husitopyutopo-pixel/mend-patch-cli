mend: one patch tool for every AI edit format. It reads unified diffs, SEARCH/REPLACE blocks, V4A patches and JSON edits, finds the lines each edit names even when their whitespace or indentation drifted, and changes every file or none, exactly as the kit's SPEC.md says.

## Run it

```sh
node main.ts fix.patch
```
